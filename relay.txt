把你的 Cloudflare Worker 域名单独写一行放在这里，index.html 会自动读取。
没有写入地址 = 不走中转（退化成「直连 → 解析线路」两级，广告照旧）。

怎么填：把下面这行的 # 去掉，再把地址换成你自己的 Worker 域名，保存即可。
# https://vrelay.abc123.workers.dev

说明：
1. 只认 http:// 或 https:// 开头的行，以 # 开头的行和本段文字都会被忽略。
2. 也可以不改这个文件，直接在网站地址后面加：
     ?relay=https://你的.workers.dev
   会自动记住，之后一直生效（想换地址就再加一次）。
3. 想让「本来就能直连的源」也走中转（只有中转才会剥广告），加 ?force=1；关掉加 ?force=0。
4. 按 F12 看 Console，第一行会打印 [中转] 已启用 / 未配置，能立刻确认有没有生效。
